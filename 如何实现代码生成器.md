# 如何实现一个类似 injectable_generator 的代码生成器

## 🎯 实现步骤

### 步骤 1: 创建一个新的 Dart 包

```bash
# 创建注解包（annotation package）
dart create -t package my_annotation

# 创建生成器包（generator package）
dart create -t package my_generator
```

### 步骤 2: 在注解包中定义注解

**my_annotation/lib/my_annotation.dart:**

```dart
/// 标记需要自动生成代码的类
class AutoGenerate {
  final String name;
  const AutoGenerate({this.name = ''});
}
```

### 步骤 3: 在生成器包中实现 Generator

**my_generator/pubspec.yaml:**

```yaml
name: my_generator
dependencies:
  build: ^2.4.0
  source_gen: ^1.5.0
  analyzer: ^6.0.0
  my_annotation:
    path: ../my_annotation

dev_dependencies:
  build_runner: ^2.4.0
```

**my_generator/lib/src/my_generator.dart:**

```dart
import 'package:analyzer/dart/element/element.dart';
import 'package:build/build.dart';
import 'package:source_gen/source_gen.dart';
import 'package:my_annotation/my_annotation.dart';

/// 核心生成器类
class MyGenerator extends GeneratorForAnnotation<AutoGenerate> {
  @override
  String generateForAnnotatedElement(
    Element element,
    ConstantReader annotation,
    BuildStep buildStep,
  ) {
    // 1. 检查元素类型
    if (element is! ClassElement) {
      throw InvalidGenerationSourceError(
        'AutoGenerate 只能用于类',
        element: element,
      );
    }

    // 2. 获取注解参数
    final className = element.name;
    final annotationName = annotation.peek('name')?.stringValue ?? '';

    // 3. 生成代码
    return '''
// Generated code for $className
extension ${className}Extension on $className {
  String get generatedName => '$annotationName';

  void printInfo() {
    print('This is auto-generated code for $className');
  }
}
''';
  }
}
```

**my_generator/lib/builder.dart:**

```dart
import 'package:build/build.dart';
import 'package:source_gen/source_gen.dart';
import 'src/my_generator.dart';

/// 配置构建器
Builder myBuilder(BuilderOptions options) {
  return SharedPartBuilder(
    [MyGenerator()],
    'my_generator',
  );
}
```

**my_generator/build.yaml:**

```yaml
builders:
  my_generator:
    import: "package:my_generator/builder.dart"
    builder_factories: ["myBuilder"]
    build_extensions: { ".dart": [".g.dart"] }
    auto_apply: dependents
    build_to: cache
    applies_builders: ["source_gen|combining_builder"]
```

## 🔍 Injectable Generator 的具体实现解析

### 关键源码结构

```dart
class InjectableGenerator extends GeneratorForAnnotation<InjectableInit> {
  @override
  Future<String> generateForAnnotatedElement(
    Element element,
    ConstantReader annotation,
    BuildStep buildStep,
  ) async {
    // 1. 扫描整个项目
    final resolver = buildStep.resolver;
    final libs = await resolver.libraries.toList();

    // 2. 收集所有带有 @Injectable、@singleton 等注解的类
    final dependencies = <DependencyConfig>[];
    for (final lib in libs) {
      for (final element in lib.topLevelElements) {
        if (element is ClassElement) {
          // 检查是否有依赖注入注解
          final injectable = _getInjectableAnnotation(element);
          if (injectable != null) {
            dependencies.add(_parseDependency(element, injectable));
          }
        }
      }
    }

    // 3. 生成注册代码
    return _generateRegistrationCode(dependencies);
  }

  String _generateRegistrationCode(List<DependencyConfig> deps) {
    final buffer = StringBuffer();

    buffer.writeln('extension GetItInjectableX on GetIt {');
    buffer.writeln('  GetIt init({');
    buffer.writeln('    String? environment,');
    buffer.writeln('    EnvironmentFilter? environmentFilter,');
    buffer.writeln('  }) {');
    buffer.writeln('    final gh = GetItHelper(this, environment, environmentFilter);');

    // 为每个依赖生成注册代码
    for (final dep in deps) {
      switch (dep.registerType) {
        case RegisterType.factory:
          buffer.writeln('    gh.factory<${dep.type}>(() => ${dep.type}());');
          break;
        case RegisterType.lazySingleton:
          buffer.writeln('    gh.lazySingleton<${dep.type}>(() => ${dep.type}());');
          break;
        case RegisterType.singleton:
          buffer.writeln('    gh.singleton<${dep.type}>(${dep.type}());');
          break;
      }
    }

    buffer.writeln('    return this;');
    buffer.writeln('  }');
    buffer.writeln('}');

    return buffer.toString();
  }
}
```

## 🛠️ 关键技术点

### 1. **Analyzer 包的使用**

```dart
import 'package:analyzer/dart/element/element.dart';
import 'package:analyzer/dart/element/type.dart';

void analyzeClass(ClassElement element) {
  // 获取类名
  final className = element.name;

  // 获取构造函数
  final constructor = element.unnamedConstructor;

  // 获取构造函数参数
  final parameters = constructor?.parameters ?? [];

  // 检查注解
  final annotations = element.metadata;

  // 获取字段
  final fields = element.fields;

  // 获取方法
  final methods = element.methods;
}
```

### 2. **Code Builder 的使用**

```dart
import 'package:code_builder/code_builder.dart';
import 'package:dart_style/dart_style.dart';

String generateCode() {
  // 创建一个类
  final myClass = Class((b) => b
    ..name = 'GeneratedClass'
    ..methods.add(Method((m) => m
      ..name = 'generatedMethod'
      ..returns = refer('String')
      ..body = Code('return "Generated!";')
    ))
  );

  // 生成代码
  final emitter = DartEmitter();
  final code = '${myClass.accept(emitter)}';

  // 格式化
  final formatter = DartFormatter();
  return formatter.format(code);
}
```

### 3. **处理依赖关系**

```dart
class DependencyResolver {
  Map<ClassElement, List<ClassElement>> resolveDependencies(
    List<ClassElement> classes
  ) {
    final dependencies = <ClassElement, List<ClassElement>>{};

    for (final cls in classes) {
      final constructor = cls.unnamedConstructor;
      if (constructor == null) continue;

      final deps = <ClassElement>[];
      for (final param in constructor.parameters) {
        final paramType = param.type;
        if (paramType is InterfaceType) {
          deps.add(paramType.element as ClassElement);
        }
      }

      dependencies[cls] = deps;
    }

    // 拓扑排序以确定注册顺序
    return _topologicalSort(dependencies);
  }
}
```

```dart
class TestStore { }
```

```dart
@InjectableInit()
void configureDependencies() => getIt.init();
```

3. **运行生成：**

```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

4. **生成的文件：**

```dart
// GetItConfiguation.config.dart
extension GetItInjectableX on GetIt {
  GetIt init({...}) {
    final gh = GetItHelper(this, environment, environmentFilter);
    gh.factory<TestStore>(() => TestStore());
    gh.lazySingleton<ApiClient<dynamic>>(() => ApiClient<dynamic>());
    return this;
  }
}
```

```dart
String _resolveGenericType(DartType type) {
  if (type is ParameterizedType) {
    final typeArgs = type.typeArguments.map((t) => t.getDisplayString()).join(', ');
    return '${type.element?.name}<$typeArgs>';
  }
  return type.getDisplayString();
}
```

## 💡 总结

实现一个代码生成器的关键步骤：

1. ✅ 定义注解（Annotations）
2. ✅ 使用 `source_gen` 创建 Generator
3. ✅ 使用 `analyzer` 分析代码 AST
4. ✅ 使用 `code_builder` 生成代码
5. ✅ 配置 `build.yaml`
6. ✅ 通过 `build_runner` 执行生成

关键在于理解 Dart 的元编程能力和 AST 分析！
