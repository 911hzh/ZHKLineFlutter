# base 目录说明

`base` 用于放置可被多个模块复用的基础能力。它不负责具体页面展示，而是沉淀接口抽象、示例 API、Store、数据模型和持久化相关代码。

## 子目录职责

- `port`：接口抽象层。业务模块需要接入 analytics、feedback、pay 等第三方能力时，先在这里定义面向业务的接口。
- `api`：当前示例工程中的网络 API 封装，包含 `RestClient` 的使用示例、接口调用和返回模型。
- `store`：状态存储和持久化示例，例如认证状态、用户数据、设置项等。

## 使用约定

`base` 中的代码应尽量保持稳定、可复用。模块代码可以依赖这里的抽象和基础能力，但这里不应该反向依赖具体模块页面。
