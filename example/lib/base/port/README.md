# port 目录说明

`port` 是接口抽象层，用于定义业务侧希望使用的能力边界。这里通常只放抽象接口、入参出参模型或少量与接口契约直接相关的类型，不放第三方 SDK 的具体调用代码。

## 适合放置的内容

- Analytics 相关接口，例如事件上报、用户属性设置、页面曝光统计。
- Feedback 相关接口，例如反馈入口、问题提交、附件上传能力。
- Pay 相关接口，例如拉起支付、查询支付结果、处理支付回调。
- 其他第三方 SDK 能力的业务抽象。

## 和 infra 的关系

`port` 只描述“业务需要什么能力”，`infra` 负责描述“这个能力如何实现”。模块层依赖 `port`，具体实现通过 `module/getIt` 注入，避免页面或业务模块直接绑定某个第三方 SDK。
