## 🔍 Injectable Generator 详细工作流程

```
步骤 1: 扫描阶段
═══════════════════════════════════════════════════════════════

─────────────────────            ─────────────────────

├─ import statements      ─────▶ ├─ name: "ApiClient"
├─ @lazySingleton               ├─ annotations: [@lazySingleton]

                                 └─ constructors: [...]
```

## 🛠️ 核心技术实现

### 1. Analyzer 的使用

```
Dart 源代码               AST（抽象语法树）
───────────────           ─────────────────────────────────
@Injectable()             CompilationUnit
class TestStore {         └─ ClassDeclaration
  final String name;          ├─ Metadata (annotations)
                              │   └─ Annotation
  TestStore();                │       └─ name: "Injectable"
                              ├─ name: "TestStore"
  void method() {             ├─ FieldDeclaration
    print(name);              │   └─ name: "name"
  }                           │       type: String
}                             ├─ ConstructorDeclaration
                              │   └─ name: "TestStore"
                              └─ MethodDeclaration
                                  └─ name: "method"

使用 Analyzer API 访问：
────────────────────────
element.name              → "TestStore"
element.metadata          → [@Injectable()]
element.fields            → [name]
element.constructors      → [TestStore()]
element.methods           → [method()]
```

### 2. 注解读取

```dart
// 源代码
@Injectable(as: [IService], env: Environment.dev)
class MyService implements IService {}

// Generator 中读取注解
ConstantReader annotation = ...

// 读取参数
final as = annotation.read('as').listValue;
// 结果: [IService]

final env = annotation.read('env').objectValue;
// 结果: Environment.dev

// 安全读取（可能为 null）
final name = annotation.peek('name')?.stringValue;
// 如果不存在则返回 null
```

### 3. 类型解析

```dart
// 处理泛型类型
void resolveType(DartType type) {
  if (type is InterfaceType) {
    // 类型名称: ApiClient
    final typeName = type.element.name;

    // 泛型参数: <User, String>
    final typeArgs = type.typeArguments;

    // 完整类型字符串
    final fullType = type.getDisplayString(
      withNullability: true
    );
    // 结果: "ApiClient<User, String>?"
  }
}

// 示例输出
ApiClient<dynamic>           → "ApiClient<dynamic>"
Map<String, List<User>>      → "Map<String, List<User>>"
Future<Response<User>>?      → "Future<Response<User>>?"
```

## 📝 生成的代码结构分析

```dart
// GetItConfiguation.config.dart
// ─────────────────────────────────────────────────

// 1. 导入必要的包
import 'package:get_it/get_it.dart' as _i174;
import 'package:injectable/injectable.dart' as _i526;

// 2. 导入项目中带注解的类
import 'package:k_line_flutter/base/api/ApiClient.dart' as _i603;
import 'package:k_line_flutter/base/TestStore.dart' as _i216;

// 3. 生成扩展方法
extension GetItInjectableX on _i174.GetIt {

  // 4. init 方法 - 注册所有依赖
  _i174.GetIt init({
    String? environment,              // 环境配置
    _i526.EnvironmentFilter? environmentFilter,
  }) {
    // 5. 创建 Helper
    final gh = _i526.GetItHelper(
      this,
      environment,
      environmentFilter
    );

    // 6. 注册依赖（按拓扑排序后的顺序）

    // Factory - 每次调用都创建新实例
    gh.factory<_i216.TestStore>(
      () => _i216.TestStore()
    );

    // Lazy Singleton - 首次访问时创建，之后复用
    gh.lazySingleton<_i603.ApiClient<dynamic>>(
      () => _i603.ApiClient<dynamic>(),
    );

    // Singleton - 立即创建，全局单例
    // gh.singleton<UserService>(
    //   UserService(
    //     apiClient: gh<ApiClient>(),
    //     authService: gh<AuthService>(),
    //   )
    // );

    return this;  // 支持链式调用
  }
}

// 使用方式
// ─────────────────────────────────────────────────
final getIt = GetIt.instance;

void main() {
  getIt.init();  // 调用生成的 init 方法

  // 获取实例
  final store = getIt<TestStore>();      // 每次都是新实例
  final api1 = getIt<ApiClient>();       // 首次创建
  final api2 = getIt<ApiClient>();       // 复用 api1

  print(api1 == api2);  // true - 同一个实例
}
```

## 💡 关键设计模式

### 1. Visitor 模式

```
Generator 遍历 AST
    │
    ├─ visitClassDeclaration()
    ├─ visitMethodDeclaration()
    ├─ visitFieldDeclaration()
    └─ visitAnnotation()
```

### 2. Builder 模式

```
DependencyConfigBuilder
    ├─ setType()
    ├─ setRegisterType()
    ├─ addDependency()
    └─ build() → DependencyConfig
```

### 3. Factory 模式

```
RegistrationFactory
    ├─ createFactoryRegistration()
    ├─ createSingletonRegistration()
    └─ createLazySingletonRegistration()
```

## 🎯 总结

Injectable Generator 的核心实现：

1. **注解驱动**: 通过注解声明依赖
2. **静态分析**: 使用 Analyzer 解析代码
3. **拓扑排序**: 确定正确的注册顺序
4. **代码生成**: 自动生成配置代码
5. **类型安全**: 保持编译时类型检查

这种方式比运行时反射更高效，因为：

- ✅ 编译时生成，运行时无开销
- ✅ 类型安全，IDE 支持良好
- ✅ 可调试，生成的代码可读
- ✅ Tree-shaking 友好
